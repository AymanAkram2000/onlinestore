# 0001 Next.js 16 and Supabase Full-Stack Architecture

We chose Next.js 16 (App Router) paired with Supabase (PostgreSQL, Storage CDN, and Auth) as a unified full-stack architecture for both the customer-facing storefront and the store owner management portal. This eliminates multi-repo overhead, delivers fast server-rendered and static catalog pages, allows direct multi-image uploads to Supabase Storage per color variant, and supports frictionless guest checkout alongside authenticated admin operations without external e-commerce platform subscription fees or layout constraints.
